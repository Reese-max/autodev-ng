**Interfaces:**

- 注入的自訂 rollback 不受 marker 限制（測試/未來 worktree 管理器自行負責）

### Task 5: daemon.ts——24/7 主迴圈（紅線 1 + 2 後半）

**Files:**
- Create: `src/daemon.ts`, `tests/daemon.test.ts`

**Interfaces:**
- Produces：
  - `interface DaemonOpts { deps: Deps; notifier: { send(t: string): Promise<boolean> }; lockDir: string; cooldownMs: number; idleSleepMs: number; sleepFn?: (ms: number) => Promise<void>; maxCycles?: number }`（sleepFn/maxCycles 供測試注入；生產不設 maxCycles）
  - `runDaemon(opts: DaemonOpts): Promise<'lock-busy' | 'stopped' | 'max-cycles'>`
- 行為規格（依序）：
  1. `acquireLock(lockDir)` 失敗 → notifier.send 一次告警 → return `'lock-busy'`（single-flight）
  2. 迴圈每輪：**try/catch 包 `runOnce(deps)`**（紅線 1）——catch 到：events 記 `runonce-crash`（quiet）、notifier.send 告警（await、失敗無妨）、指數退避 sleep（cooldownMs×2^連續crash數，上限 10 分鐘）後 continue；連續 crash 5 次 → notifier 告警「daemon 連續崩潰暫停」→ sleep 30 分鐘、計數歸零
  3. runOnce 正常回傳：`'stopped'` → break 回 `'stopped'`；`'idle'`/`'cost-hard-stop'` → sleep idleSleepMs；其他 → sleep cooldownMs
  4. 每輪檢查 `shouldSendDigest`（用 UTC 今日）→ true 就 `buildDigest` + `notifier.send`，**送達（true）才 `markDigestSent`**——送失敗下輪重試（每日必達，鐵律 #6）
  5. 事件路由告警：runOnce 回傳 `'blocked'`/`'cost-hard-stop'`/`'preflight-failed'` 時 notifier.send 對應訊息（blocked 訊息含任務文字前 80 字）
  6. finally `releaseLock`
  7. `acquireLock` 若 throw（EPERM 類，紅線 2 分類後浮出）→ notifier 告警 + rethrow（daemon 起不來要炸給排程器看，不可假活）
