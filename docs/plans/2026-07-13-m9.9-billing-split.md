# M9.9 訂閱引擎成本分離帳 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 日成本頂只踩真金帳（billed），訂閱制引擎（codex）的估值照記帳但不煞車——修掉「保護不存在的錢包卻真擋工作」。

**Architecture:** attempts 表加 `engine` 欄（冪等 migration）＋db 提供 billed 查詢（fail-safe：空/未知 engine＝真金）；scheduler 踩頂改 billed；digest/cmdCost 顯示「真金｜訂閱名義」雙數字。spec：`docs/specs/2026-07-13-billing-split-design.md`。

**Tech Stack:** TypeScript、better-sqlite3、zod、vitest（serial）。

  billedCostForLocalDay(day: string, offsetHours = 0, subscriptionEngines: string[] = []): number {
    if (subscriptionEngines.length === 0) return this.costForLocalDay(day, offsetHours)

  }
